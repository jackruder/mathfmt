# Plan: mathfmt version zero

Spec: `docs/superpowers/specs/2026-11-05-mathfmt-design.md`. Built inline in the
session of 2026-11-05 on the person's instruction ("just build all now"); the
same task list is the shape a phalanix wave would take, one task per seat.

Each task names the files it touches, the interface it produces and the tests
that prove it. Tasks 1 and 2 are independent of the rest; 3 through 9 chain.

## 1. Infrastructure (independent)

Files: `flake.nix`, `flake.lock`, `tests/dev.sh`, `.phalanix/rig.nix`,
`.phalanix/roles/*.md`, `CLAUDE.md`, `README.md`, `.pre-commit-hooks.yaml`.

- Dev shell with cargo, rustc, clippy, rustfmt, rust-analyzer, python3;
  `CARGO_VENDOR_DIR` from `importCargoLock` so `tests/dev.sh cargo test` needs
  no network. Package via `buildRustPackage`. Checks: test, clippy, fmt.
- `tests/dev.sh`: drops `PHALANIX_*`/`PG*`, puts nix on PATH, enters the shell
  from the repo root; when the command is `cargo`, injects the vendored source
  replacement.
- Rig: lead + task/review/question templates through `phx.kind`, roles written
  for this repository's commands. Validate with `phalanix up --dry-run`.
- Proof: `nix develop -c cargo --version`; `nix build`; the dry run.

## 2. Data tables and generator (independent)

Files: `tools/gen-table.py`, `crates/mathfmt-core/data/{unicode-math.tsv,
alphabets.tsv, latex.tsv, signatures.tsv}`.

- Generator reads `unicode-math-table.tex`, writes the first two TSVs.
- `latex.tsv` hand-curated: codepoint, preferred pdflatex spelling, aliases.
- `signatures.tsv`: argument counts and text-argument flags for the kernel,
  amsmath, amssymb, bm, unicode-math `\sym…`.
- Proof: row counts match the spec's expectations; the Rust loader (task 3)
  parses every row.

## 3. Tables in Rust

Files: `crates/mathfmt-core/src/{table.rs, atom.rs}`.

- `Atom` enum, `Style` enum with `FromStr`/`Display`.
- `Table::builtin()` parses the embedded TSVs once; lookups: codepoint → atom,
  name → atom, atom → unicode char (Option), atom → latex spelling (Option),
  style command name → style.
- Tests: every data row loads; `\in`, `∈`, `𝐱`, `ℝ`, `\varphi`, `\phi`,
  `\emptyset`, `\mathbbm` resolve as the spec says.

## 4. Scanner

Files: `crates/mathfmt-core/src/scan.rs`, `src/source.rs` (offsets → line/col).

- `scan(text, &Config) -> Document { regions: Vec<MathRegion>, defs: Vec<Definition> }`
  implementing §5 with text/math recursion. Math regions carry their body span
  and kind; the body is lexed in task 5, but the scanner must already find the
  terminator by lexing, so tasks 4 and 5 share the lexer.
- Tests: all §14 edge cases.

## 5. Lexer and parser

Files: `src/lex.rs`, `src/parse.rs`, `src/signatures.rs`.

- `lex(body) -> Vec<Token>`; `parse(tokens, &Signatures, &Macros) -> Tree`.
- Text arguments become nested documents via the scanner.
- Tests: round-trip print of every fixture equals the input; argument binding
  for `\frac`, `\sqrt[3]{x}`, `\mathbf x`, `\left\langle`.

## 6. Macro definitions and expansion

Files: `src/macros.rs`.

- Parse the definition forms in §7 into `Macro { name, params, body_tokens, opaque_reason }`.
- `expand(call, &Macros, depth) -> Result<Vec<Token>, Opaque>`.
- Tests: `\R`, `\KL[2]`, `\DeclareMathOperator`, `\def\foo#1{…}`, a recursive
  macro hits the depth, `\if` makes it opaque.

## 7. Resolver

Files: `src/resolve.rs`.

- Walk the tree, emit `Occurrence { span, atom, source_spelling, kind }` per §8,
  including styled-group runs and inlined macro calls; mark groups left whole.
- Tests: §8 examples, `\mathbf{\sigma_\theta}` left whole, `\mathbf{xy}` two atoms.

## 8. Profiles, config, printer, edits

Files: `src/config.rs`, `src/profile.rs`, `src/print.rs`, `src/edit.rs`, `src/diag.rs`.

- `Config::load(path)`, `Config::find(from_dir)`, defaults for `unicode` and
  `ascii`, unknown keys rejected.
- `print(occurrences, &Profile, &Table) -> (Vec<Edit>, Vec<Diagnostic>)` with
  run merging and the spacing rule.
- `apply(text, edits) -> String`.
- Tests: the spacing rule, run merging, `no-latex-spelling`, idempotence on a
  sample.

## 9. Library facade and CLI

Files: `src/lib.rs` (`convert(text, &Options) -> Outcome`, `inventory`, `rename`),
`crates/mathfmt/src/main.rs`.

- Filter mode, `--write`, `--check`, `--diff`, `--emit`, `--format json`,
  `--strict`, `-j`, `rename`, `table`. Parallel files with rayon.
- Tests: `crates/mathfmt/tests/golden.rs` over `tests/fixtures/`, plus CLI
  tests for exit codes.

## 10. Fixtures

Files: `tests/fixtures/*`.

At least: `basic-to-unicode`, `basic-to-ascii`, `macros-inlined`,
`macros-folded`, `styled-runs`, `text-nesting`, `verbatim-skipped`,
`definitions-untouched`, `roundtrip-paper-snippet` (a paragraph in the style of
the ICML paper), `rename-frak-to-cal`, `no-latex-spelling`.

## 11. Smoke test and docs

- `mathfmt --check --diff` over `~/dev/ddssm-icml2027` read-only; record the
  counts in the README's "what it does to a real paper" section.
- README: install, the two profiles, pre-commit snippet, the known collapses
  (`cal`/`scr`, `bf_greek`).

## 12. Verification

`cargo test --workspace`, `cargo clippy --workspace -- -D warnings`,
`cargo fmt --check`, `nix build`, `nix flake check`. Record counts in the
commit message of the verification commit.
