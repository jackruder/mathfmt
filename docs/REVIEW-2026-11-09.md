# Review of the three waves of 2026-11-08

An independent adversarial review of `744406d..90834dc`: style distribution
(`6c0124d`), `--verify` (`0f7539c`) and parameterized notations (`90834dc`).
The reviewer worked in its own checkout with pdflatex and pdftoppm on PATH
and reproduced every finding by running the binary. Twenty-two findings; all
were reproduced again here before anything was changed. The behaviour that
changed is in the spec's amendment of 2026-11-09, "the second review".

Each finding: what was wrong, the smallest input, what was done, and the
test that now pins it.

## Found while fixing

- **An unbraced argument.** `\hat\alpha` became `\hat α`, which no way of
  reading Unicode under pdflatex survives (measured for project mode: the
  macro takes one byte), and `\hat 𝐱` became `\hat\mathbf{x}` under the
  `ascii` profile. Fixed; fixtures `unbraced-argument` and
  `unbraced-argument-ascii`.
- **Declarations missed a rewritten notation's literals.** The compile check
  on the new fixture for F10 failed: the `𝒩` of a rewritten `𝒩(μ, Σ)` was
  not declared, so the snippet preamble left it to the package's script
  font. Fixed in `Engine::atoms_used`.

## Claims in the README and the spec

The status line still called notations unbuilt; the notation example showed
a space the tool does not add; `holes bind whatever sits between the
literals`, `modulo symbols` and `idempotent` were false as F8, F10 and F9
show and are true now; exit status 2 for an original that does not compile
was undocumented; `Known collapses` said two and listed three. All corrected.

## Ruled on, not changed

- An unterminated region's warning says `left as is` and its symbols are
  converted all the same. That is version zero's behaviour and harmless; the
  wording should change.
- `--verify` may add fonts to the user's TeX font cache (bbm is METAFONT
  only). Any compile does.
- A `differs` fixture holding several cases (`style-distribution-repairs`
  has six) can hide one of them changing. The harness reads only the
  verdict. Splitting them, or pinning the differing box, is still to do.
- Still untested: `--preamble FILE`, an unknown `--engine`, a page-count
  difference.

## Probed and found sound

Document mode compiling the converted copy of an input; sources never
modified; macro files under paths with spaces and non-ASCII characters;
unique build directories for equal basenames; the temporary directory
removed; `\mathbf{\sigma_\theta}` and `\bm{\mu_k^{j}}` in both profiles;
whitespace, comments, operators and nested commands inside a style group;
nested notations, `\KL p q`, notations inside `\sqrt`, `\frac`, `\text{$…$}`
and `\underbrace`; config errors for bad holes; malformed inputs.
